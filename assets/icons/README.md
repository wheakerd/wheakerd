# Profile icons

`terminal.svg`, `layers.svg`, and `settings.svg` are from [Feather v4.29.2](https://github.com/feathericons/feather/tree/v4.29.2/icons), under the [MIT license](LICENSE).

Only the theme-aware stroke color, formatting, and accessibility metadata are customized. Their geometry is unchanged. Icons use teal `#0f766e` on light backgrounds and `#5eead4` when the browser prefers a dark color scheme; the fallback stroke is `#0d9488`.
